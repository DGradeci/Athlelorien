# Levy Paper Data Caches

This folder is for local processed data generated by the Levy-paper pipeline.
Large cache files are intentionally ignored by Git.

The public Git repository tracks only this README and
`cache_bundle_manifest.csv` from this folder. The manifest lists the optional
external cache files required to regenerate figures without AWS.

The frozen processed bundle is shared outside Git by the project maintainers.
Extract it into the repository root without flattening directories. A correct
installation places the primary parquets under
`analysis/levy_paper/data/processed/all_team_2020_2021_sticky_active/`.

## Rebuild Requirements

To rebuild this folder from scratch, a user needs:

- local NFF schedule spreadsheets at the paths documented in
  `analysis/levy_paper/metadata/schedules/README.md`;
- pitch registry in `analysis/levy_paper/metadata/pitches/toppserien_pitches.json`;
- AWS/S3 access to the raw Soccermon tracking data;
- authorised AWS credentials supplied through the normal AWS environment,
  credential files/profile, or an optional local `.env`.

The tracked `.env.example` documents supported variable names. Real `.env`
files and processed parquet caches should stay local and must not be committed.
The original NFF workbooks are also local-only and are intentionally excluded
from the public repository.

## Figure Reproduction Without AWS

The Git-tracked `figures/main_figures/`, `figures/supplementary_material/`,
and `figures/source_data/` folders are enough to inspect the submitted figures
and source tables without AWS or parquet caches.

Downstream figure notebooks can fully regenerate figures from this primary
processed cache without re-reading the raw AWS/S3 data. If sharing with a collaborator who
does not have AWS access but needs computational regeneration, provide this
cache folder as a separate data bundle.

The separate cache bundle should preserve paths relative to the repository
root, for example:

```text
analysis/levy_paper/data/processed/all_team_2020_2021_sticky_active/...
```

Figure 4 and Figure 5 generate this derived model-cache folder:

```text
processed/figure4_fig5_crossfitted/
```

Build it from the primary hazard-interval cache with:

```powershell
.\.venv\Scripts\python.exe analysis\levy_paper\scripts\build_figure4_figure5_model_cache.py
```

The derived folder may be retained to avoid refitting, but it is not a separate
data dependency and can be deleted and rebuilt at any time.
