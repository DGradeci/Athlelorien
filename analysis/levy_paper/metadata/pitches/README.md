# Pitch Registry Attribution

`toppserien_pitches.json` is a curated extraction of football-pitch geometry
from OpenStreetMap, retrieved through the Overpass API and supplemented only by
analysis-specific registry labels.

OpenStreetMap data are available under the Open Data Commons Open Database
License (ODbL) 1.0.

OpenStreetMap attribution and ODbL requirements.
